Sobre Mim

Sou estudante de Análise e Desenvolvimento de Sistemas com foco em desenvolvimento Full Stack. Gosto de construir aplicações do zero — desde a interface até a integração com banco de dados — sempre com atenção à organização do código, performance e boas práticas.

Atuo principalmente com HTML, CSS e JavaScript no front-end, além de Node.js, Express, APIs REST, MySQL e PostgreSQL no back-end. Também possuo conhecimentos em Java e Python.

Sempre tive interesse por tecnologia, e foi no desenvolvimento que encontrei a forma de colocar esse interesse em prática. Aprendo melhor construindo — cada projeto se torna uma oportunidade de consolidar conhecimentos e explorar novas soluções.
